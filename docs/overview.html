Foundry V1 Blueprint

把模型能力，锻造成
可信的工程结果。

一个全新、独立、开源的本地 coding-agent runtime：在 Windows 11 的 Git 仓库中读取、修改、验证，并用可追溯证据交付结果。

产品定位 一个内核，两条模型路径

个人开发连接官方支持的 ChatGPT 订阅登录；企业环境连接内部 Gateway。认证与协议可替换，agent loop 与工具始终只有一套。

Windows 11Python 3.12离线 wheel交互式 CLI
核心架构

Provider 只翻译，Runtime 做决定

外部输入都被视为数据，而不是权限；任何工具调用都不能绕过策略和审计。

V1 承诺

完成，不靠模型自述

只有真实证据满足完成门槛，session 才能标记 completed。

  • 最终检查当前 Git status / diff
  • 验证声明关联命令、exit code 与时间
  • 区分已有修改、Foundry 修改与并发修改
  • JSONL 事件流本地留存，遥测默认关闭
  • 轮数、工具数、时长与输出全部有界
Agent Loop

每一步都有闸门

单一运行时拥有完整控制流。

  • 模型提出结构化 tool call
  • Schema 与路径预检
  • Policy：ALLOW / ASK / DENY
  • 执行、限时、清理进程树
  • 脱敏记录并返回结果
安全边界

Trusted host ≠ Sandbox

V1 面向可信仓库，减少误操作，但不虚构隔离能力。

文件边界拒绝 traversal、ADS、junction 与 reparse point
保护现场支持 dirty worktree，写前校验内容摘要
凭证隔离Token 不进入提示词、日志、异常或仓库配置
交付路径

先证明，再集成

当前处于 Phase 0：蓝图与外部协议验证。

  • Fake backend 跑通离线 vertical slice
  • Windows 文件、Git 与进程安全
  • 企业 Gateway 真实端到端验证
  • 安装、供应链与 V1 hardening
关键研究门槛
ChatGPT 订阅登录仅在确认存在官方支持的独立客户端方案后实现；不使用私有接口或复制其他客户端凭证。
