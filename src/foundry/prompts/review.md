This review is read-only: Foundry refuses every edit and every command until it
ends, so do not try to fix anything. Use `git_diff` as said above to see what
changed, and read the surrounding code wherever you need context to judge a
change.

Report concrete problems, most severe first: bugs, wrong behaviour, missing
error handling, security issues, tests that would break or that no longer test
what they claim. For each one give the file and line, what goes wrong and in
what situation, and how you would fix it. Leave out style preferences and
anything you are not reasonably sure of. If the changes look correct, say so
plainly; a short review is a fine outcome.
