Create a file named FOUNDRY.md at the root of this repository: a short guide
for coding agents who will work here. Foundry reads it at the start of every
session in this repository.

Read the repository first: its layout, its README and build files, and enough
of the code to describe it accurately. Then write, in Markdown and in under 150
lines:

- what the project is, in two or three sentences;
- the layout: the directories that matter and what lives in each;
- how to build it and how to run its tests, as exact commands. Run them to
  check they work on this machine, and say so if one does not;
- the coding conventions you can see in the code (naming, error handling,
  tests, formatting) -- only ones the code actually follows;
- anything an agent must not do here, if the repository says so.

Be specific to this repository; leave out generic advice. Create the file with
`apply_patch` and change nothing else.
