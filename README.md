# Foundry

Foundry is a planned, local-first coding-agent runtime for trusted Windows 11
development machines. The project is currently in its blueprint phase: no
runtime behavior should be inferred from this repository yet.

The source of truth for the proposed V1 is:

- [中文设计总览（单页 HTML）](docs/overview.html)
- [Product requirements](docs/product-requirements.md)
- [Architecture](docs/architecture.md)
- [Delivery roadmap](docs/roadmap.md)
- [Open questions and research log](docs/open-questions.md)
- [Architecture decisions](docs/decisions/README.md)

The documents deliberately distinguish confirmed product intent from proposals
and unresolved research. In particular, ChatGPT subscription authentication is
a gated feasibility study, not an assumed public integration contract.
